A private personal assistant.

Hikari is a single-user assistant application. It is used by one person, for their own calendar and mail. There is no public service, no sign-up and no other users.

Google access

  • Calendar — reads upcoming events, and creates or removes events when asked.
  • Gmail — reads recent mail to answer questions about it, and sends a message only on an explicit request.

This application exists so that one account can authorise its own assistant. How the data is handled is described in the privacy policy.
