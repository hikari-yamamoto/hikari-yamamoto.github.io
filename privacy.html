Privacy policy

Last updated: 27 October 2026

Hikari Yamamoto ("Hikari") is a personal assistant application operated by a single individual for their own use. It has no other users, no customers and no commercial purpose.

What data is accessed

When you authorise Hikari with a Google account, he requests these scopes:

  • https://www.googleapis.com/auth/calendar — to read calendar events and to create or delete events on his own calendar.
  • https://www.googleapis.com/auth/gmail.readonly — to read message subjects, senders and bodies in order to answer questions about them.
  • https://www.googleapis.com/auth/gmail.send — to send a message, only when the user explicitly asks for one to be sent.

Where the data goes

Hikari runs entirely on the user's own computer. Calendar and mail data are fetched directly from Google's APIs at the moment a question is asked, held in memory to produce an answer, and discarded. They are not written to a database, not copied to any server operated by Hikari, and not retained after the request completes.

OAuth tokens are stored locally on that computer, readable only by the owning user account, and are never transmitted anywhere except to Google's own token endpoint.

Sharing

No data is sold, rented, shared with third parties, used for advertising, or used to train any machine learning model. The only parties involved in a request are Google and the user's own computer.

Answers are produced by sending the relevant text to Anthropic's Claude API, which processes it to generate a reply. Anthropic's handling of that text is governed by their own privacy policy at anthropic.com/legal/privacy.

Retention and deletion

Nothing from Google is retained. To revoke Hikari's access entirely, remove the app at myaccount.google.com/permissions; the stored token becomes invalid immediately. Removing the local token file from the computer deletes the local copy.

Changes

If this policy changes, the date at the top of this page is updated.
